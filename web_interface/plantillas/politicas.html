Políticas de paro

Una política decide, en cada época, si el entrenamiento debe detenerse. Aquí puedes escribir las tuyas: se guardan en un archivo Python que también puedes editar a mano y recargar.

El código que escribas aquí se ejecuta en el proceso del servidor. Por eso solo se puede editar con el servidor en localhost.
